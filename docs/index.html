Tentang XSAYT
Full ori UI, bukan tiru Rayfield. Glassmorphism, spring 60fps, 40% lebih ringan.

↑ Interactive mockup — coba klik toggle/slider/dropdown & ganti tema

Kenapa lebih gacor dari Rayfield?

Glassmorphism
Blur acrylic + neon gradient animated, corner 16px. Bukan flat membosankan.
Spring 60fps
Back easing smooth, bukan Quad kaku. Terasa premium di Delta.
Mobile Premium
Touch, swipe minimize, haptic. Rayfield buggy di Android, XSAYT lancar.
Toast + Sound
Success/warn/error dengan sound & accent bar. Lebih keren dari Notify.
Slider + Input
Bisa drag + ketik angka langsung. Rayfield cuma drag.
Searchable Dropdown
Multi + search + check anim. Lengkap buat hub besar.

Quick API

local Hub = XSAYT.New({
  Title="XSAYT • GACOR",
  Theme="Cyber"
})
local Tab = Hub:AddTab({Name="Combat", Icon="rbxassetid://6031265976"})
local Sec = Tab:AddSection("MAIN")

Sec:AddToggle({Title="Godmode", Desc="...", Callback=function(v) end})
Sec:AddSlider({Title="Speed", Min=16, Max=500, Callback=function(v) end})
Sec:AddDropdown({Title="Weapon", Options={"Katana","Gun"}, Search=true})
Hub:Toast({Title="GACOR!", Type="success"})
